# SMS転送のシート仕様

構成の正本はgas/menu.jsのsheetSchema_とgas/Code.jsのSETTINGS_ROWS_です。

## 初期化の契約

「SMS転送 → 初期設定」（GASエディタのsetupも同じ処理）で不足シートと不足設定を追加します。既存値とログは上書き・削除しない。初期設定を繰り返しても合言葉・設定・ルール・ログは保持され、例行や警告保護は増殖しません。

ヘッダー不一致では変更前に停止。既存の列順や名前を自動修復せず、バックアップと個別移行を行います。完全に空のシートはヘッダーから作成できます。受信時は不足シートを作らず、初期設定が必要なエラーを返します。

初期化は受信と同じScriptLockを最大30秒待ちます。取得できなければ変更しません。途中のサービスエラーでは不足分が残る場合があり、原因を解消して再実行します。初期化はメール送信やログ保持による削除を行いません。

## settings

列は「項目 / 値 / 説明」。B列を編集します。A・C列には警告のみの保護を設定します。

| 項目 | 初期値・選択肢 |
|---|---|
| バージョン | コードの版。初期設定が毎回 `lib.js` の `VERSION` で書き戻す。利用者は変更しない |
| 合言葉 | 新規生成。既存値は保持。値を明示的に消して初期設定すると再生成 |
| 転送先アドレス | 空欄なら自分宛 |
| ラベルの付け方 | SIM名 / 端末名 / 固定名 / 付けない。既定SIM名 |
| 固定ラベル名 | 空欄 |
| 親ラベル | SMS |
| ログの保持行数 | 1000。不正値の扱いはOPERATIONS.md参照 |
| 未認証も記録する | はい / いいえ。既定いいえ |
| ウェブアプリURL | 空欄。ウェブアプリをデプロイ後、公開画面のURL（/execで終わる）を貼り付ける |

バージョン行は既存ブックでは先頭のデータ行へ挿入され、毎回の初期設定で現在の版へ更新します。ウェブアプリURLはシートへの明示入力だけを使い、旧スクリプトプロパティや自動取得からは補完しません。URLは形式だけを確認し、公開状態・到達可能性は保証しません。再実行でも入力値は保持します。

旧TOKEN・MAIL_TO・LABEL_MODEは不足設定へ移し、読み戻し成功後に旧プロパティを削除します。他のプロパティは保持します。既存の説明文は変更しません。

## log

8列の順序は「logged_at / received_at / device / from / body / mailed / reason / sim」。ヘッダーは保持件数に含めません。

fromのデータ行は文字列書式。記録時の先頭アポストロフィも維持し、先頭ゼロを保持します。bodyのデータ行は折り返し。送信結果とログ保持の仕様はOPERATIONS.md参照。

## filter

列は「type / field / pattern / memo」。typeはallow / deny、fieldはfrom / body / device / simの選択肢です。patternは正規表現、memoは説明用です。

type空欄の例は無効。データ行がない場合だけ2行の例を追加し、利用者がtypeを選ぶまで受信判定に影響しません。既存ルールがある場合は例を追加しません。denyを先に評価し、allowがない場合は全通しです。

## 管理書式

ヘッダー行だけ太字、1行固定。列幅はスキーマ定義から設定します。ログの文字列・折り返しとfilterの選択肢は2行目から物理最大行まで適用します。全行へのヘッダー書式や行高変更は行いません。初期設定の再実行はこの管理書式・入力規則を再適用しますが、セル値は保持します。
