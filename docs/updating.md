# 更新手順（受け取った人向け）

新しい版のコードが出たときの更新方法です。
**必ず「既存デプロイの更新」を行います。「新しいデプロイ」は作らないでください**
（新しいデプロイは URL が変わるため、settings の「ウェブアプリURL*」の貼り直しと
スマホ側 SmsForwarder の Webhook URL 入れ直しが必要になります）。

設定（`settings` シート）・受信履歴（`log`）・フィルター（`filter`）はすべて残ります。

## 1. コードを差し替える

1. スプレッドシートで「拡張機能」→「Apps Script」
2. 左のファイル一覧から各 `.gs` / `.js` ファイルを開き、新しい版の内容で全選択・貼り替える
3. **`appsscript.json` も差し替える**。このファイルは既定で非表示です:
   - エディタ左の歯車「プロジェクト設定」→「**appsscript.json マニフェスト ファイルをエディタで表示する**」を ON
   - ファイル一覧に `appsscript.json` が出るので、新しい版の内容へ貼り替える
   - manifest だけ古いままだと、貼り替えは見かけ上成功して実行時にエラーになることがあります
4. 新しい版で `.js` ファイルが増えている場合は、ファイル一覧の「**＋**」→「スクリプト」で
   同じ名前のファイルを追加し、中身を貼り付けてください（貼り替えだけでは新規ファイルは取り込めません）

## 2. 既存デプロイを更新する

1. 右上の「デプロイ」→「**デプロイを管理**」
2. 稼働中のデプロイを選び、鉛筆アイコン → バージョンを「**新バージョン**」→「デプロイ」
3. URL は変わりません。「ウェブアプリURL*」の貼り直しも不要です

## 3. 初期設定を再実行する

スプレッドシートの「SMS転送」→「初期設定」を1回実行してください。
新しい版で増えた設定行の追加・バージョン行の更新が行われ、既存の値は保持されます。

## バージョンの確認

`settings` シートの「バージョン」行の値が、入手した版の番号（`CHANGELOG.md` 参照）と
同じになっていれば更新完了です。
