# トラブルシューティング

まず `log` シートを見ます。SMS が GAS へ届いていれば必ず1行増え、転送されなかった理由が `reason` 列に残ります。

| 症状 | 原因 | 対処 |
|---|---|---|
| SmsForwarder のログに `{"ok":false,"error":"unauthorized"}` | `token` が `settings` の「合言葉*」と違う | Sender の Web params の `token=` を手順メールの値へ貼り直す |
| 応答が空または HTML | URL が `/exec` で終わっていない、または「アクセス: 全員」でデプロイされていない | デプロイ完了画面の URL をそのまま使う。アクセス権は「デプロイを管理」で確認 |
| `log` に行はあるが `mailed` が `no` | `filter` シートで落ちている | `reason` 列を見る。`deny:...` なら deny 一致、`no-allow-match` なら allow に未一致 |
| `log` に行が増えない | 端末から GAS へ届いていない | SmsForwarder の「Log」画面で送信結果を確認。権限・電池最適化・自動起動を再確認 |
| メールは来るがラベルが付かない | 「ラベルの付け方」や「固定ラベル名」が空 | `settings` の値を確認。「固定名」なら「固定ラベル名」が必須 |
| 件名の番号の先頭ゼロが消える | `log` の `from` 列の書式が壊れている | 列を「書式なしテキスト」に戻す（値自体は `'` 前置で保存済み） |
| 急に全部のメールが来なくなった | Gmail の送信クォータ超過の可能性 | GAS の実行ログにクォータ系エラーが出ます。個人アカウントの送信は1日あたり上限があり、翌日まで待つか送信量を減らします。Apps Script のクォータ画面で確認できます |
| 古い `log` 行が消えた | 「ログの保持行数」を超えた自動削除 | 仕様です。残したい行は増やすか別シートへ退避 |
| 「スマホの設定手順をメールで送る」で案内が出る | 「ウェブアプリURL*」が空または形式が違う | `/exec` で終わる公開 URL を貼る。行自体が無ければ「初期設定」で追加されます |

## `?resend=1` について

公開 URL に `?resend=1` を付けて開くと、認証なしで所有者宛へ手順メール（トークン入り）が再送されます。
第三者が踏んでもトークンは所有者へしか届きませんが、迷惑送信・送信クォータ消費の経路にはなります。
自分以外に URL を渡さないでください。不要な再送を止めたい場合は公開デプロイ自体を無効化するしかありません。

## 端末側（SmsForwarder）

- 権限を一度拒否したあとで挙動がおかしい → アプリを一度停止し、権限を許可し直す
- Xiaomi / OPPO / Huawei 系で止まる → 「自動起動」と「電池最適化の除外」を端末設定で許可
- SIM 名が取れず `SIM1` のようなラベルになる → 電話の権限が未許可か、「備考（Remark）」が未設定
